# Последний сигнал

Браузерный прототип о ремонтном дроне, который просыпается на затонувшей подводной лодке.

## Запуск

Игра не требует сборки: откройте `index.html` в браузере или отдайте папку через любой статический веб-сервер.

## Управление

- `A` / `D` или стрелки — движение;
- `W`, `↑` или пробел — короткое зависание;
- `E` — взаимодействие с терминалом.

## Первый вертикальный срез

Три отсека и три мини-игры: щит питания, насос и сонар. После каждого ремонта лодка оживает, а в финале сонар принимает неизвестный сигнал.
